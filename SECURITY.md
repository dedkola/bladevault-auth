# Security Policy

BladeVault Auth handles Google OAuth codes and tokens for [BladeVault](https://bladevault.pro), so security reports are taken seriously.

## Reporting a vulnerability

**Please do not open a public issue.** Report privately through [GitHub Security Advisories](https://github.com/dedkola/bladevault-auth/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. You will get a reply as soon as possible, and a fix will be released before details are made public.

## Supported versions

Only the code currently deployed at `https://auth.bladevault.pro` (the `main` branch) is supported.
